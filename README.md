# Tanbir Hasan Jewel — Developer Portfolio

A modern, responsive personal portfolio showcasing my skills, projects, achievements, and journey as a Full-Stack Developer.

## ✨ Features
- Responsive desktop and mobile design
- Interactive Day/Night theme switch
- Floating particles and smooth animations
- About, Experience, Education, and Tech Stack
- Projects, Achievements, and Certificates
- Contact and social media integration
- SEO optimization and accessibility support

## 🛠️ Tech Stack
- **Frontend:** Next.js, React.js, TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Tools:** Git, GitHub, VS Code

## 🚀 Getting Started

**Requirements:** Node.js 20.9+ and npm.

```bash
git clone  https://github.com/tanbir78/portfolio_1
cd <project-folder>
npm install
npm run dev
```

Open: `http://localhost:5000`

## ⚙️ Available Commands

```bash
npm run dev       # Development server
npm run build     # Production build
npm start         # Production server
npm run lint      # ESLint
npm run typecheck # TypeScript check
```

## 📁 Customization

- `src/content/profile.ts` — Personal information, education, skills, and experience.
- `src/content/projects.ts` — Project details and links.
- `src/lib/achievements.ts` — Achievements and awards.
- `src/lib/certifications.ts` — Certificates.
- `src/app/globals.css` — Theme colors and animations.
- `public/` — Images, projects, and certificates.

## 🌗 Theme
- **Day Mode:** Warm ivory with elegant pastel accents.
- **Night Mode:** Deep indigo with soft lavender accents.
- Theme preference is saved locally.

## 🌐 Deployment

Deploy easily with [Vercel](https://vercel.com/).

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Configure `NEXT_PUBLIC_SITE_URL`.
4. Deploy your portfolio.
